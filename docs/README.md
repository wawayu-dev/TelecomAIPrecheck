# 项目文档

本目录只保留面向需求评审、技术评审、部署验收和面试展示的正式文档。开发阶段的 Issue 过程记录不再作为交付文档维护；历史内容仍可通过 Git 提交记录查询。

## 阅读顺序

| 文档 | 适合读者 | 主要内容 |
| --- | --- | --- |
| [业务需求调研](业务需求调研.md) | 产品、业务、面试官 | 为什么选择运营商投诉核查、真实流程与 AI 边界 |
| [产品需求说明](产品需求说明.md) | 产品、开发、测试 | 用户角色、业务流程、功能范围、业务规则和验收条件 |
| [系统设计说明](系统设计说明.md) | 架构师、开发、面试官 | 系统架构、异步任务、状态机、数据模型、安全和审计设计 |
| [API 接口文档](API接口文档.md) | 前后端、宿主系统开发 | 接口、权限、请求响应、错误码和幂等约束 |
| [部署运行手册](部署运行手册.md) | 开发、运维、演示人员 | Docker Compose、环境变量、启动、健康检查和版本标签 CI |

## 辅助材料

- `evidence/` 保存合成数据联调结果和页面截图，只作为验证材料，不代表真实运营商生产数据或业务效果。
- `TelecomAIPrecheck/docker-compose.yml` 与 `.env.example` 是当前整栈演示的部署文件。
